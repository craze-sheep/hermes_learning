# Dataset Validation for Physics Simulations (Kubric/Blender)

Validate datasets generated by Kubric (Blender + PyBullet) for correctness of depth maps, segment masks, metadata, and rendering artifacts.

## When to Use

- After generating a batch of simulation samples, before committing to training
- When suspecting rendering bugs (e.g., corrupted depth, misaligned segments)
- As a QA gate before large-scale dataset production

## Directory Structure (Expected)

```
S{x}/L{y}/{id}/
  {id}.mp4              # rendered video
  {id}.npz              # depth map (keys: depth [T,H,W] float32, unit [str])
  video.json            # metadata: fps, num_frames, camera, units
  object_static.json    # list of object definitions (id, type, static/dynamic, physics params)
  dynamic/{frame}/
    {frame}.png          # rendered RGB frame (H,W,3) uint8
    force_matrix.json    # inter-object forces per timestep
    object_segment/
      {obj_id}.npz       # mask (H,W) uint8 {0,1}, object_id, segmentation_id, frame_num
    object_dynamicjson/
      {obj_id}.json      # per-frame physics: position, velocity, force, visible_area
```

## Validation Steps

### Step 1: Structure Completeness

Check that every expected file exists for each sample. Missing files indicate interrupted rendering.

```python
import os
required_exts = ['.mp4', '.npz', 'video.json', 'object_static.json']
# Also check dynamic/{frame}/ has .png, object_segment/, object_dynamicjson/
```

### Step 2: Depth Map Sanity

The most common failure mode. Check:

```python
import numpy as np
d = np.load(f"{id}.npz")['depth']
# Expected shape: (num_frames, H, W), dtype float32
# Check for:
#   - inf/nan values
#   - Unrealistic values (>100m for typical scenes, camera at ~8m)
#   - Blender far-clipping-plane artifacts (~1e10)
#   - Frame-to-frame consistency (depth should change smoothly)

is_bad = d.max() > 100  # threshold for typical indoor-scale scenes
```

**Known pattern**: depth corruption can be strongly correlated with sample ID (e.g., all odd IDs, or every 3rd ID). Always check for ID-correlated patterns:

```python
from collections import Counter
bad_ids = [sid for sid, d in zip(all_ids, all_depths) if d.max() > 100]
# Check mod patterns
for mod in range(2, 6):
    dist = Counter(i % mod for i in bad_ids)
    print(f"mod {mod}: {dict(dist)}")
```

### Step 3: Segment Mask Validation

```python
seg = np.load(f"dynamic/{frame}/object_segment/{obj_id}.npz")
# Expected: mask shape (H,W), dtype uint8, values {0,1}
# Check:
#   - mask.shape matches depth H,W
#   - No overlap between different object masks
#   - frame_num matches directory name
#   - object_id/segmentation_id matches object_static.json

overlap = np.logical_and(seg1['mask'], seg2['mask'])
assert overlap.sum() == 0, "Masks overlap!"
```

### Step 4: Cross-Field Consistency

```python
import json
vid = json.load(open("video.json"))
# vid['num_frames'] should match depth.shape[0]
# vid['cameras'][0]['resolution'] should match depth.shape[1:3]
# vid['cameras'][0]['depth_path'] should match the npz filename

static = json.load(open("object_static.json"))
# len(static) should match number of object_segment/*.npz files per frame
# segmentation_id in static should match segmentation_id in segment npz
```

### Step 5: Visual Overlay Verification

Overlay segment masks on rendered frames to verify spatial alignment:

```python
from PIL import Image
import numpy as np

png = np.array(Image.open(f"dynamic/{frame}/{frame}.png"))
seg1 = np.load(f"dynamic/{frame}/object_segment/1.npz")['mask']
seg2 = np.load(f"dynamic/{frame}/object_segment/2.npz")['mask']

vis = png.copy()
vis[seg1 > 0] = [255, 0, 0]    # red = object 1
vis[seg2 > 0] = [0, 255, 0]    # green = object 2
Image.fromarray(vis).save(f"/tmp/overlay_{frame}.png")
# Then use vision_analyze to check alignment
```

## Pitfalls

1. **Blender far-plane values (~1e10)**: Not inf/nan, but still invalid. Always check `max() > threshold`, not just `isinf`/`isnan`.
2. **ID-correlated corruption**: If depth bugs follow a pattern by sample ID, the bug is in the rendering script's sample loop, not in individual samples. Don't waste time checking per-sample — check the pattern first. See references/blender-depth-bug.md for confirmed root cause.
3. **Ground mask covers ~99% in top-view**: For orthographic top-down cameras, the ground plane occupies nearly the entire image. This is correct, not a bug.
4. **Small object masks in perspective view**: Objects far from camera may have only 10-100 pixels. This is expected for 128x128 resolution with perspective cameras.
5. **Kubric Cylinder class**: `kb.Cylinder` works in the official Docker image (`kubricdockerhub/kubruntu`) but may not exist in older local installs. If using Cylinder and getting errors, verify the Docker image version. L7 data confirmed working with `kb.Cylinder(scale=(radius, radius, height/2.0))`.
6. **Unit field**: depth unit is stored as a string in the npz (e.g., 'm' for meters). Always verify it matches video.json units.
7. **Docker OOM Kill**: WSL2 with ≤8GB RAM + Blender rendering (~1.6GB per container) is at high OOM risk. Check `dmesg -T | grep -i oom` when containers disappear unexpectedly. Docker `--rm` flag makes killed containers vanish without a trace.
8. **PyBullet ground penetration**: High-speed spheres with small radius and low rolling friction can penetrate the ground plane. Check `z_final < 0` in sphere scenarios. Example: S2 L6 had 33/324 spheres with z_final < 0 (worst: -2.94m).
9. **Empty directories on generation failure**: When a sample generation fails mid-way (e.g., OOM kill), empty directories may be left behind. Always check for `<scenario>/<level>/<id>/` with 0 files inside.
10. **Orthographic top-view mask invariance**: Sphere masks in orthographic top view do NOT change with height (the projected circle is always the same size). This is correct behavior, not a bug. Front/perspective views SHOULD show mask movement.

## Batch Statistics Script

For large-scale validation, aggregate across all samples:

```python
import os, numpy as np
base = "database/S{x}"
results = {'total': 0, 'depth_bad': 0, 'missing_seg': 0}
for lvl in sorted(os.listdir(base)):
    for sid in sorted(os.listdir(os.path.join(base, lvl))):
        npz = os.path.join(base, lvl, sid, f"{sid}.npz")
        if os.path.exists(npz):
            results['total'] += 1
            d = np.load(npz)['depth']
            if d.max() > 100:
                results['depth_bad'] += 1
print(results)
```
